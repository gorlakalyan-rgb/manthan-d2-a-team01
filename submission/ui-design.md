## 3. Table and view states matrix

| State | What the user sees | Where implemented | Evidence |
|---|---|---|---|
| Loading | Layout-shaped skeleton shimmer (avatar + title + rows), `role="status"` with hidden label | `components/ui.jsx` `Loading`, Dashboard `Skeleton` | brief, before data arrives |
| Refreshing | Data stays; small spinner "Refreshing…" in an `aria-live` region | `ui.jsx` `DataView` | — |
| Empty | Tinted icon tile, title, one-line explanation, next action (e.g. "File your first claim") | `ui.jsx` `EmptyState` (My claims, Inbox "You're all caught up", Payouts, Audit trail) | — |
| Populated | Dense table: sticky header, mono amounts right-aligned, chips with text, age chip colour + text | `QueueTable.jsx`, Payouts, Policy | screenshots 05, 08, 10, 11 |
| Filtered-empty | "Nothing matches these filters" + "Try widening the amount range or clearing filters" + Reset | `AuditQueue.jsx`, `Employees.jsx` | — |
| Selected / bulk | Row tint + left bar, header checkbox indeterminate, count + ₹ total, floating bulk bar | `AuditQueue.jsx`, `QueueTable.jsx` | screenshot 08 |
| Bulk result | Per-row "✓ approved" / "✕ reason" column and a summary alert | `AuditQueue.jsx` results | test E2E-09 (ops) |
| Error / retry | Red alert with plain-language message and **Try again** button; never a blank page | `ui.jsx` `ErrorState` | — |
| 409 stale state | "Someone else acted first", claim reloads to the latest status, error toast | `Review.jsx` | — |
| Offline / API down | Full-width red banner under the top bar; sidebar status dot turns red | `Shell.jsx` `useHealth` | SRE drill |
| Forbidden | "Not available for your role" card + button home; API also returns 403 | `App.jsx` `Guard` | Playwright E2E-05 |
| Phone (< 720 px) | Tables become labelled cards (`data-label` per cell) | `app.css` `table.responsive` | screenshot 07 |

## 4. Accessibility checklist (grounded in implemented controls)

| Check | Implementation |
|---|---|
| Skip link | "Skip to main content" (`.skip-link`, `Shell.jsx`); "Skip to form" on sign-in, forgot-password and reset-password |
| Focus management | `<main tabIndex=-1>` receives focus on every route change; dialogs use native `<dialog>` with focus trap; Esc closes palette, sheets, drawer |
| Visible focus | 2 px focus ring token `--focus-ring` on all inputs, buttons, links |
| Keyboard operation | Ctrl K palette (arrow keys + Enter), `?` shortcut sheet, G-then-letter navigation, N new claim, T theme, `[` sidebar; Review: A approve, S send back, R reject, J/K lines, Esc back; Tab reaches Submit at 390 px (Playwright E2E-02) |
| Forms | Every input has a visible `<label>` (search boxes use `aria-label`); the sign-in role picker is a `radiogroup` with arrow-key support; Caps Lock warning on password; errors use `aria-invalid` + `aria-describedby` and a text message with icon |
| Live regions | Toast stack `role=region aria-live=polite`; totals, bulk results and refresh state announced; errors use `role="alert"` |
| Colour not alone | Every status chip carries text ("Approved", "Needs review"); policy reasons pair an icon with words; age chips show hours/days |
| Contrast | Token pairs chosen for WCAG 2.2 AA (≥ 4.5 : 1) in both light and dark |
| Charts | Every chart card has a **Chart / Table** toggle with a real `<table>`; SVGs have `role="img"` and an `aria-label` listing the values |
| Reduced motion | `MotionConfig reducedMotion="user"`, CSS `prefers-reduced-motion` and the in-app **Reduce motion** switch turn animations off (decorative loops included) |
| Touch targets | Controls ≥ 40 px (44 px on coarse pointers) |
| Language and formats | `lang="en-IN"`, ₹ with lakh grouping, all times in IST |
